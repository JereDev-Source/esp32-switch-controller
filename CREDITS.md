## Project

[JereDev](https://github.com/JereDev-Source) created and tested the ESP32
integration. Codex assisted with development, debugging, and documentation.

If you reuse this project, keep the license and attribution notices and credit

## References and third-party projects

- [Poohl/joycontrol](https://github.com/Poohl/joycontrol): NFC MCU flow used by

  `0b79bf7569c07d078576a6fa0e7fd0c212bb5ee3`.
- [mart1nro/joycontrol](https://github.com/mart1nro/joycontrol): controller
  emulation and SPI memory reference.
- [dekuNukem/Nintendo_Switch_Reverse_Engineering](https://github.com/dekuNukem/Nintendo_Switch_Reverse_Engineering):

- [BlueKitchen/BTstack](https://github.com/bluekitchen/btstack): Bluetooth stack
  and ESP32 port.
- [Espressif/ESP-IDF](https://github.com/espressif/esp-idf): ESP32 framework and
  HID/GAP example code.
- [Kenneth MacKay/micro-ecc](https://github.com/kmackay/micro-ecc): cryptography
  library included with BTstack.
- [ndeadly/switch2_controller_research](https://github.com/ndeadly/switch2_controller_research):
  Switch 2 protocol research referenced by local experimental code.
